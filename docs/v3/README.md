# Sakura v3 架构与交付状态

v3 已成为唯一构建和发布版本。Web、Bot 和开放 API 是平等入口，共享统一账号和业务层；Bot 不访问数据库，Worker 独立运行。旧 v2 仅保存在 `legacy/v2`，用于最终导入、对账和审计，不再参与 CI 或镜像构建。

## 阶段状态

| 阶段 | 状态 | 已完成内容 |
|---|---|---|
| 第 0 阶段：冻结和盘点 | 已完成 | v2 入口、模型、任务、配置、测试和迁移决策基线 |

## 不可违反的边界

- Web 不调用 Bot；
- Bot 不直接访问 PostgreSQL 或 Redis；
- API 启动不会启动 Bot，Bot 启动不会执行迁移；
- Worker 停止不影响 API 基础查询；
- 管理操作必须经过服务端权限校验和审计；
- 设置变更必须有版本记录，凭据不得明文存储或出现在日志中。
