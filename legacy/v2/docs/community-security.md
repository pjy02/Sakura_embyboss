# 影评、通知、权限与审计

第四阶段增加影评社区、站内通知、可管理角色权限和增强审计检索。所有数据继续存储在现有 MySQL 中，并通过 FastAPI 的登录身份、CSRF 和权限依赖进行服务端校验。

## 影评社区

用户可以按作品唯一标识提交一篇评分和短评，支持年份、1–10 分评分和剧透标记。新影评默认进入“待审核”：

- 管理员可以通过、拒绝或隐藏影评，并填写审核备注。
- 用户可以修改待审核或被拒绝的影评，也可以删除自己的影评。
- 已发布影评支持点赞和举报；同一用户只能点赞一次、举报一次，不能举报自己的内容。
- 审核结果会生成站内通知，创建、修改、删除、举报与审核操作都会进入审计日志。

## 站内通知

个人中心新增通知收件箱、未读数量、单条已读、全部已读和分类开关。通知分类包括系统、账单、工单、求片和影评。

系统会自动生成以下通知：

- 充值订单入账或未通过；
- 工单收到管理员公开回复；
- 求片状态发生变化或 MoviePilot 完成入库；
- 影评审核结果。

管理员可以向单个 Telegram ID 或全部现有用户发送站内广播。站内通知偏好不会改变 Bot 原有 Telegram 消息行为。

## 角色与权限

所有者可以：

- 新建自定义角色；
- 修改 `admin`、`operator`、`auditor` 和自定义角色的权限；
- 删除没有成员使用的自定义角色。

`owner` 和 `user` 属于受保护角色，不能修改或删除。自定义角色名称只能包含小写字母、数字、下划线和短横线。角色权限在每次接口身份校验时重新解析，无需重启容器。

新增权限域：

- `reviews:read`、`reviews:update`、`reviews:*`
- `notifications:read`、`notifications:send`、`notifications:*`
- `roles:manage`
- `audit:export`

## 审计增强

操作记录支持按关键词、操作来源、结果、资源类型和时间范围组合筛选。详情抽屉展示请求 ID、资源、IP 地址和结构化业务数据。拥有 `audit:export` 权限的管理员可以按当前筛选条件导出最多 10000 条 UTF-8 CSV 记录，每次导出本身也会写入审计日志。

## 数据迁移

部署新版本后，`migrate` 容器会自动执行 `20260731_06`，创建：

- `media_reviews`
- `review_reactions`
- `review_reports`
- `user_notifications`
- `notification_preferences`

迁移只向系统角色合并新增权限，不会覆盖已有自定义权限。
